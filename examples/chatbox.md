# Use Mervex in Chatbox

1. Open **Chatbox → Settings → AI Model Provider → Add Custom Provider** (OpenAI API)
2. Set:
   - **API Host:** `https://api.mervex.cc.cd`
   - **API Key:** your Mervex key — free at https://mervex.cc.cd/auth
   - **Model:** `Msrfteam/Mervex-ai-v0.1-lite` (or any id from the /models list)
3. Save and chat.

All `Msrfteam/...` models work — the full catalog with live success/latency stats: https://mervex.cc.cd/models
